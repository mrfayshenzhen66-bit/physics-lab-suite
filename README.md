## 目录结构

```
├── index.html          # 合集门户首页（卡片导航 + 模块筛选 + 搜索）
└── labs/
    ├── plank-conveyor/ # 板块·传送带实验室
    ├── 3d-force/       # 三维受力分析实验室
    ├── ac-dc/          # 交流变直流实验室
    ├── lc-osc/         # 电磁振荡实验室
    ├── sound/          # 声波实验室
    ├── optics/         # 光现象仿真实验室（13 合 1）
    └── lens-scope/     # 望远镜与显微镜
```

## 如何新增一个实验室

1. 在 `labs/` 下新建目录，放入单文件 `index.html`
2. 在门户首页顶部 `LABS` 数组里登记一条：
   `{module:'电学', title:'…', path:'labs/电学-xxx/index.html', …}`
3. 门户自动生成卡片、模块计数与搜索索引，提交推送后 GitHub Pages 自动更新
